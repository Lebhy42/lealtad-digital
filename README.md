# Lealtad Digital

Página para vender tarjetas de lealtad digitales, catálogo, apartados y página web a negocios locales.

- `index.html`: la página de ventas. El número de WhatsApp está al final, en `const WHATSAPP`.
- `demo/`: demo para probar (copia de la app de Jireh shop en modo demostración; los datos se quedan en el navegador de quien la prueba). PIN de la tienda: 2603.

Se publica en Cloudflare (Workers & Pages) con el comando `npx wrangler deploy`.
